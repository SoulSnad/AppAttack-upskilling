## 1. Initial Upskilling Resources for on-boarding Juniors

For on-boarding juniors that wish to do pen testing you will be required to have done a minimum amount of upskilling before you can begin pen testing

### 1.1 Minimum Pentesting Upskilling

The minimum requirement to begin pen testing is that of completing the (insert number of modules) from the Jr Penetration Tester course at [Tryhackme](https://tryhackme.com), (Note: You will have to create an account in order to access the free modules)

Mandatory Jr Pen Tester Modules to complete are as follows:

* **Offensive Security Intro** 
* **Defensive Security Intro**
* **Passive Reconnaissance**
* **Active Reconnaissance**
* **Nmap Live Host Discovery**
* **Burp Suite: Repeater**

* **(insert module name here)**

### 1.2 Basic Understanding of Latex

Code Review Reports, Penetration Test Reports and Final Reports are handled using LaTeX, thus you will need to learn know how to use LaTeX if you haven't already been using it.

Resources to help you learn LaTeX and compile vulnerability reports can be found in the [Latex-Guide](../guides/Latex-Guide/latex-guide.mdx)
