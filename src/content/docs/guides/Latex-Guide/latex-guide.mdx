## 4. Git Cleanliness Reminder

When uploading your completed findings to the repository:
* **Upload:** `.tex`, `.pdf`, and `.png` image files.
* **Do Not Upload:** Compiler build artifacts (`.aux`, `.log`, `.out`, `.synctex.gz`).
